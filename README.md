Stone Paper Scissors – Mini Project

A simple console-based Stone–Paper–Scissors game built using Python.
This project is created as part of the CSFCP Unit 4 Mini Project to learn Git, GitHub, VS Code, and basic software development workflow.


---

🔹 Project Description

This is a classic Stone-Paper-Scissors game where:

The user selects stone, paper, or scissor

The computer randomly selects an option

The winner is decided based on game rules

The game displays the result after each round


This project demonstrates:

User input handling

Python conditionals & loops

Random module usage



---

🔹 Features

✔ Player vs Computer gameplay
✔ Randomized computer choice
✔ Clean and simple UI
✔ Replay option
✔ Input validation


---

🔹 How to Run the Project

1. Install Python (if not installed)


2. Open the project folder in Visual Studio Code


3. Run the following command in terminal:



python rockpaperscissor.py


---

🔹 Game Rules

User Choice	Computer Choice	Result

Stone	Scissors	User Wins
Paper	Stone	User Wins
Scissors	Paper	User Wins
Same choice	Same choice	Draw
